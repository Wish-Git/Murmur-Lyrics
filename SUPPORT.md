# Support

## Start Here

1. Confirm you installed the package for the correct browser.
2. Confirm the reader footer shows Murmur v0.7.0.
3. Refresh YouTube after installing or updating.
4. Read [Installation](docs/INSTALLATION.md).
5. Work through [Troubleshooting](docs/TROUBLESHOOTING.md).
6. Check [Frequently asked questions](docs/FAQ.md).

## Open An Issue

Use the GitHub bug-report form for a reproducible problem or the feature-request form for a proposal. Search existing issues first.

A strong report includes the browser version, Murmur version, operating system, YouTube URL, reproduction steps, detected title, selected Genius match, and a privacy-cropped screenshot.

## What Support Can Cover

- Installation and updates.
- Chrome and Opera GX behavior.
- YouTube and YouTube Music detection.
- Reader layout and accessibility.
- Automatic track changes.
- Search, matching, and extraction regressions.
- Release verification.

Support cannot provide or redistribute lyrics, bypass third-party access restrictions, recover browser accounts, or guarantee that every ambiguous title maps to the intended song.

## Security Reports

Follow [SECURITY.md](SECURITY.md) and report vulnerabilities privately.
