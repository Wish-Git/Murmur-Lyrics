# Contributing

Thank you for helping improve Murmur.

## Repository Scope

This is a public distribution and documentation repository. It contains release ZIPs and public project documents, not the private development source tree.

Useful contributions here include:

- Reproducible bug reports.
- Chrome and Opera GX compatibility reports.
- Documentation corrections.
- Installation and troubleshooting improvements.
- Accessibility observations.
- Focused feature proposals.
- Reports of YouTube or Genius markup changes.

Implementation pull requests are not expected because the underlying development tree is not hosted here. Do not decompile and republish package files as a source pull request.

## Report A Bug

Use the bug-report issue form and provide:

- Browser name and exact version.
- Murmur version and package type.
- Operating system.
- Reproduction steps.
- Expected and actual behavior.
- YouTube URL when it is safe to share.
- Detected track and selected Genius match.
- A cropped screenshot when layout is involved.

Do not include passwords, cookies, authentication tokens, private profile data, or full copyrighted lyrics.

## Request A Feature

Describe the user problem first, then the desired behavior. Explain whether it affects Chrome, Opera GX, YouTube, YouTube Music, the popup, matching, or the lyrics reader.

## Documentation Changes

Documentation pull requests are welcome.

1. Keep instructions step by step.
2. Keep browser-specific behavior clearly labeled.
3. Do not claim a store release exists unless it has been published.
4. Do not add private source, the owner's manual, keys, credentials, or copied lyrics.
5. Test relative links before opening the pull request.

## Conduct

Be direct, respectful, and focused on observable behavior. Remove private information from screenshots and logs. Security reports belong in a private GitHub security advisory, not a public issue.
